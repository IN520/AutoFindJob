# 央国企校招追踪表

自动聚合**国聘网**（国资央企招聘平台）+ **国家大学生就业服务平台**（教育部官方）两个源的在招校招岗位，
生成一张可筛选、可按截止日期排序、临近截止自动高亮的网页报表。

这是一个 **AI Agent Skill**（`SKILL.md`），可被 Claude Code、Cursor 等 AI 编码代理加载，
让 Agent 在你提出「帮我找央国企校招岗位」时自动调用本脚本。

## 作为 Skill 使用

- **Claude Code**：克隆后放到 `~/.claude/skills/`（或项目 `.claude/skills/`），对话中说「抓一份央国企校招追踪表」即可。
- **各大主流AI**：仅需把该项目地址/zip文件告诉AI，并说安装并运行该skill即可。
- **Cursor / 其他 Agent**：直接读取本目录的 `SKILL.md` 与 `AGENTS.md`。
- **独立使用**：无需任何 Agent，直接运行脚本（见下）。

## 快速开始

```bash
python3 tracker.py          # 抓取 + 增量入库 + 导出
open jobs.html              # 查看报表（macOS）
```

零第三方依赖，只需 Python 3（标准库）。建议每天跑一次，或设个定时任务。

| 文件 | 说明 |

## 数据源说明

### 国聘网（主源，含截止时间）
- 接口：`gp-api.iguopin.com/api/jobs/v1/recom-job`（职位推荐池，约 400 条）
- 筛选：只保留 `recruitment_type_cn == 校园招聘`
- 优势：**有截止时间 `end_time`**、公司性质（国企/事业单位/国家机关）、学历、薪资、专业、完整岗位描述

### 国家大学生就业服务平台（补充源）
- 接口：`ncss.cn/student/jobs/jobslist/ajax/`
- 筛选：单位性质 = 国有企业 / 机关·事业单位·非营利机构
- 限制：匿名接口每个查询最多返回 100 条，故只取各性质前 100 条

## 字段

公司、岗位、城市、学历、月薪(K)、公司性质、规模、招聘人数、福利、专业要求、发布日期、**截止日期**、投递链接、来源。

## 已知限制

1. **国聘网**推荐池仅约 400 条（20 页），且其职位搜索接口 `/api/jobs/v3/list` 需要登录态/签名，暂未接入——意味着会漏掉推荐池之外的岗位。
2. **NCSS** 匿名接口有 100 条/筛选上限，超过需登录；且无截止时间字段。
3. 因此本表是「在招央国企校招岗的一个高质量子集」，不是严格意义的全量。
